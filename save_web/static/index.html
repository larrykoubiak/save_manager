Memory Card Browser

One row per save, one column per device.

Version history settings

Saves are grouped by platform and game serial. Original card positions are source information; destination slots are chosen when building target memory cards. Distinct copies on sources are retained separately from old history.

Sources

Dates use each card’s own clock. Offline columns show their last known copies.

Recent activity

Scans and reviewed transfers

Shared memory cards are checked every five minutes. Stable changes, including new saves and deletions, update the other cards. Offline devices keep pending updates. Every replacement backs up the destination first.

Device

Add a device

Start FTP on the console, disconnect other FTP clients, then use Scan now. Enable writes in a location to allow verified FTP uploads. Offline devices retain their last inventory.

Scheduled scans update the inventory. Memory-card sync groups also monitor their selected devices every five minutes.

Remove device

Remove this device and all its locations from Save Manager. Library saves, memory card files, backups, and history stay intact. Sync groups using these cards will pause.

Remove location

Remove this location and its cards from Save Manager. Memory card files, backups, and transfer history stay intact. Sync groups using these cards will pause.

Memory cards

Sync a PSP game

Only this game’s saves are exchanged. Other games on the shared card stay untouched. The first copy prepares a dedicated game card on the PSP; its current contents are backed up.

Sync memory cards

Choose matching copies of one shared memory card, with the same capacity. A changed card replaces the others after it settles, including additions and deletions. Different starting cards and independent changes require choosing a source.

Choose the copy to sync

This card will replace the entire contents of the other selected cards, including additions and deletions. Their current cards will be backed up first. Offline copies will update when they return, unless they have changed independently.

Transfer a save

Only the selected slot changes. Other slots, configuration and icons are preserved.
